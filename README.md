# HouseKeeper · E.V.

**一个会自己学习的家庭语音助手 —— 以及让它从 0 长到成熟的那条 Loop。**

大模型接进智能家居，三分钟就能 demo，但没人真的天天用：接了大模型的方案**对家里传感器感知很弱**；
小爱同学这类反应快、但**全靠人工堆指令，换个说法就懵**。

E.V. 想把这两件事同时做好，而且**不靠人一条条堆规则 —— 它自己学**。

> E.V. 出自《蜘蛛侠：崭新之日》，是 Peter Parker 自己造的 AI 助手 —— 不是 Stark 施舍的战衣系统。
> 「自己造、自己学、越用越懂主人」，正是这个项目想做的。

## 三层架构

```
一句人话
  ↓
L1 精确规则      dict 查表                       ~0ms
L2 本地小模型    字符 n-gram + 逻辑回归，带弃权    ~1ms
L3 云端大模型    兜底，并把结果固化回 L1/L2        ~1300ms
  ↓
执行：HASS 控制 / 读传感器 / 外部脚本 / 多步场景
  ↓
人话回答 + 落 traces（Loop 的观测数据）
```

**关键设计是「弃权」**：L2 输出置信度，低于阈值主动降级给大模型。
因为实测证明，分类器会在「开/关」「热/冷」这类极性上**自信地答错** ——
宁可多走几次大模型，也不要自信地做错事。

## 两个 Loop

```bash
python3 ev/bootstrap.py    # 0 → 成熟：只给一份能力清单，自动跑到可用状态
python3 ev/daily.py        # 1 → n：从真实交互记录持续改进（建议挂夜间定时）
python3 ev/agent.py        # 用起来（默认 dry-run，不会真动设备）
python3 make_report.py     # 把任意一次 run 渲染成可演示的网页
```

`daily.py` 的阶段就是 Loop 五要素：

| 要素 | 在这里是什么 |
|---|---|
| **Goal** | 少走大模型、少被纠正、能力边界更宽（全部可量化） |
| **Action** | 本地优先，搞不定才问大模型；同时把理解固化成本地能力 |
| **Observe** | 是否本地命中、延迟、有没有被纠正、换个说法还对不对 |
| **Feedback** | 观测回流；捷径「晋升」前必须先验证一致 |
| **Adapt** | 过了考卷门槛才换模型，旧版留备份可回滚 |

## 冷启动把踩过的坑固化成了流程

用它的人不用重蹈：

| 阶段 | 防的是什么坑 |
|---|---|
| 体检能力注册表 | 漏登记设备 → 模型拿「最像的」顶上（实际事故：说「开主卧空调」开了客厅空调） |
| **自动生成辨析** | 易混能力没写辨析 → 开/关判反、房间搞错 |
| **先造考卷、再造教材** | 拿考卷当教材 → 分数虚高（实测 100 道考题里 49 道被训练过） |
| 造训练数据 | 每类样例太少 → 分类器根本训不起来 |
| 自动选阈值 | 拍脑袋定阈值 → 白白多走大模型却换不来准确率 |
| 审计 L1 规则表 | 写死的过度泛化 → 最高优先级、不会弃权、错了永久生效 |

## 双模型分工

```
Claude（离线 ~10s）   造数据 / 造考卷 / 质检标注 / 体检注册表
      ↓ 产出教材和考卷
DeepSeek（运行时 ~1s） L3 意图兜底 / 纠正解析
      ↓ 边教边留标注
本地小模型（~1ms）     L1/L2 快路径，不会就弃权
```

**分工依据不是「谁更强」，而是「错了的代价」**：运行时错一次能当场纠正；
离线任务错了会**固化进所有后续学习**。

## 它能做什么

```
你> 现在适合开窗吗
E.V.> 客厅 27.8℃，湿度 57%，室外 19℃ 下雨。还行；外面在下雨，开窗注意飘雨。
      （没有「适不适合开窗」这种现成读数，是综合室内温湿度和室外天气判断出来的）

你> 把卧室灯打开
E.V.> 主卧灯开了 → 主卧灯
你> 不对，我说的是客厅
E.V.> 已撤销主卧灯，客厅灯开了 → 客厅灯      （自动撤销 + 重做 + 学进去）

你> 开浴霸和热水器
E.V.> 浴霸开了，热水器开了                    （多意图，本地 2ms 拆解）

你> 现在去公司要多久
E.V.> 现在开车到公司大概 24 分钟              （固化成脚本，直接调地图接口）
```

## 换成你家

改两个文件 + 跑一条命令，见 **[HOWTO.md](HOWTO.md)**。
换智能家居平台（米家 / HomeKit / 自研网关）只需改 `ev/resources.py` 一个文件。

## 说明

- `ev/capabilities.md` 与 `ev/bindings.py` 是作者家的真实配置，作为示例保留 —— 换成你家的即可
- 密钥全部走 `.env`（见 `.env.example`），不入库
- 运行时产生的学习数据、交互记录、模型快照均不入库

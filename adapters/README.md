# 适配层：把 E.V. 接到不同的语音端

E.V. 本体是纯文本的：**一句话进，执行 + 一句话出**。
接任何语音端，只需要把「ASR 出来的文本」喂进来、把「回答文本」交给 TTS。

```
        ┌──────────── 语音端（小爱音箱 / 智能眼镜 / ...）
        │  ASR ──► 文本
        │                    ┌─────────────────┐
        └────── HTTP ───────►│  ev_server.py   │
               POST /ask     │   E.V. 本体      │
        ┌────── 回答文本 ◄───│ 理解→执行→回话   │
        │                    └─────────────────┘
        │  TTS ◄── 文本
        └────────────
```

**为什么用 HTTP 而不是把 E.V. 塞进语音端进程**：
- 两边能各自重启（改能力清单不用动音箱、音箱掉线不影响 E.V.）
- 一个 E.V. 可以同时服务多个语音端（音箱 + 眼镜 + 命令行）
- 语音端换平台时，E.V. 一行不用改
